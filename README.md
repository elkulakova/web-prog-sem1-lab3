# 2048

Веб-версия игры 2048: поле 4×4, очки, отмена хода, сохранение сессии и таблица рекордов.
Стек — HTML, CSS и чистый JavaScript (DOM API).

## Как открыть локально

1. Клонировать репозиторий.
2. Открыть `index.html` в браузере (или через Live Server).

Условие лабораторной: [`TASK.md`](./TASK.md).
